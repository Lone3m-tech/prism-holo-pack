# PRISM · 典藏全息拆包互动台（Native Web Tactile Card Pack）

> 零前端框架、零外部音效文件、零第三方运行时依赖的原生 Web 撕包抽卡交互实验（`HTML` + `CSS 3D` + `SVG` + `Canvas 2D` + `Web Audio API`）。

灵感致敬海外设计工程师 Yash Bharadwaj 的网页交互实验 [`holo.yashb.xyz`](https://holo.yashb.xyz/)。由于原站未附带开源许可，本项目采用 Clean-room 洁净室方式从零重写，并扩展了双光效舞台、摇包验货、96 段可控撕裂、炉石式悬念翻牌、3 包必金保底与 12 卡 3D 图鉴闭环。

---

## 快速运行

本项目**零第三方依赖（无需 `npm install`）**，但因为使用了浏览器原生 `ES Module`，不能直接双击 `index.html`（`file://` 协议会被浏览器拦截），通过任意本地 HTTP 静态服务即可打开：

```bash
# 方式一（推荐）：使用内置 Node 零依赖服务（需 Node.js 18+）
node server.mjs
# 或 npm start

# 方式二：无 Node.js 时使用系统自带 Python 一行启动
python3 -m http.server 4180
```

终端启动后访问 `http://127.0.0.1:4180` 即可游玩（完整适配桌面鼠标与移动端触屏）。也可直接用 VS Code 的 `Live Server` 插件右键 `index.html` 打开。

如需用内置数学 SDF（有向距离场光线步进）脚本重新生成 `assets/characters/` 下的 12 张 3D 角色透明 PNG（需 Node.js 18+）：

```bash
npm run generate-assets
# 或 node scripts/generate-assets.mjs
```

### 上手操作

1. **验包与切换**：按住并左右晃动鼠标（或点击底部 `摇包验包`），封口会透出最高稀有度光晕；可随时点 `欧皇待命` 切换全闪模式，或右上角切换 `暗房聚光 / 白昼展台`。
2. **控向撕包**：按住顶部 `◀ TEAR SEAL ⟶` 区域横向拖动即可控向撕开铝箔封条（撕到一半松手会弹性卷曲回弹），撕穿到底触发彩虹喷流并吐出 5 张卡牌。
3. **翻牌与图鉴**：点击卡背单翻或按住横扫连翻，再点正面进入 3D 激光全息放大检视；左下角 `典藏册` 支持点击已收录卡牌随时重温 3D 特效。

## 核心特性

- **镀铝复合膜卡包物理撕裂**：240Hz 子步进弹簧求解器驱动，支持封口横向控向撕裂（96 段锯齿断茬）、12 段级联卷曲铝箔内衬、松手弹性回弹、撕口实时金属火花、32 道矢量彩虹喷流，以及装填欧皇包时的 `360°` 炫金觉醒翻转。
- **实时程序化声效（`src/sound.js`）**：无任何外部 `.mp3` / `.wav` 文件，全部铝箔揉捏声、随撕裂速度变调的撕纸音、摇包微响、悬念感应风铃与五阶稀有度翻牌和弦均由 `Web Audio API` 实时运算合成。
- **暗房聚光 / 白昼展台双光效舞台**：搭载竖纹建筑光学玻璃景深舞台与胶片微噪点抑制暗部色带，右上角支持实时切换明暗光效。
- **分区全息典藏卡牌工艺**：SVG 玑镂星盘压纹卡背配合高罕呼吸光环；卡面采用选择性全息遮罩分层——虹彩与对旋激光折射仅作用于画窗与斜切金属框，下半部哑光铭牌独立成层确保排版高对比清晰。
- **完整可循环抽卡玩法**：
  - 拆封前可点击 **摇包验包**（或左右快速晃动鼠标）从封口透视本包最高稀有度光晕；
  - 5 卡展开后支持单点、**按住横扫连翻** 与 **一键翻开**，高罕翻牌触发三环扩散冲击波与舞台微震；
  - 内置 `3 包必金` 保底计数器、**欧皇全闪包** 切换拨杆，以及 `localStorage` 持久化的 **12 卡丝绒典藏图鉴**（已收录卡牌可直接点击唤出 3D 检视）。

## 项目结构

```text
.
├── index.html                  # 页面结构：顶栏字标、三维舞台、底部控制台与图鉴弹窗
├── package.json                # 极简项目元信息与启动脚本（零依赖）
├── server.mjs                  # 零依赖本地静态预览服务（支持端口冲突自动顺延）

├── assets/
│   ├── brand/                  # 舞台顶标与光学玻璃展厅底图（暗房/白昼双套）
│   └── characters/             # 算法生成的 12 张立体角色与吉祥物透明 PNG

    ├── cards-config.js         # 唯一数据入口：12 卡池、稀有度权重与卡包主题配色

    └── styles.css              # 舞台光影、铝箔材质、双面 3D 卡牌与全息着色样式
```

## 自定义你自己的卡面（3 分钟改造）

所有卡池数据与视觉主题均集中在 `src/cards-config.js`：

1. **只换角色图**：修改对应卡牌对象的 `character.image` 指向透明背景 `PNG` / `WebP`；若不需要动态眼球跟随，设置 `character.rigged = false`。
2. **直接出整张完稿卡面**：在卡牌对象上添加 `fullArtImage: 'assets/your-card.png'`，系统会自动保留全息闪膜、卡背悬念翻牌、厚度斜切与 3D 视差倾斜。
3. **网站子目录静态部署**：项目内全部资源均为纯相对路径（`src/` 与 `assets/`），可直接将 `index.html`、`src/`、`assets/` 复制到任意静态站点子目录中（访问时保留结尾斜杠，如 `/demos/holo-pack/`）。
